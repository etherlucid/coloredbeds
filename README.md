# Colored Beds Mod

A 16-color bed mod backported for Minecraft 1.5.2 (Minecraft Forge 7.8.0.735+).

## Features
- **16 Colored Beds**: Implements all 16 wool colors for beds (White, Orange, Magenta, Light Blue, Yellow, Lime, Pink, Gray, Light Gray, Cyan, Purple, Blue, Brown, Green, Red, Black).
- **Vanilla Replacement**: Safely replaces vanilla block ID 26 and item ID 355 to maintain 100% full sleeping functionality, GUI sleep rendering, and entity player bed state without breaking vanilla or modded mechanics.
- **Custom Textures**: Full texture pack support under domain `coloredbeds` (`mods/coloredbeds/textures/blocks/` and `mods/coloredbeds/textures/items/`).
